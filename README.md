# CASIO-Style Scientific Calculator

A modern, web-based scientific calculator built with **JavaScript, HTML, and CSS**, inspired by classic CASIO designs.

## Features

* Basic operations: `+`, `-`, `×`, `÷`
* Advanced functions:

  * `log` (base 10)
  * `ln` (natural logarithm)
  * `√` (square root)
  * `x²` (square)
* Percentage calculations `%`
* Parentheses support `( )`
* Delete (`DEL`) and clear (`AC`) functionality
* Clean and responsive UI

## 📦 Installation

1. Clone the repository:

```bash
git clone https://github.com/Mr-Robot486/Calculator
```

2. Open the project folder:

```bash
cd calculator
```

3. Run in browser:

* Open `calculator.html` in your browser

## Usage

* Click buttons or use keyboard input (if supported)
* Perform both simple and scientific calculations
* Use `AC` to reset and `DEL` to remove last input
